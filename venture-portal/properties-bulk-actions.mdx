## Custom properties

Properties are team-defined, single-select fields on every deal — **Cohort**, **Award Category**, **Programme**, anything. They're set on the company page or in bulk, filterable everywhere (lists, dashboards, widgets), and organisations can limit which offices see each property.

<Tip>
  Properties are how cohorts work on Caplia: a `Cohort` property with options like *Q3 2026* gives you cohort filters, cohort dashboards, and cohort-wide chat channels for free.
</Tip>

## Bulk actions

Select rows in any list (or select all) and the action bar appears:

| Action | What it does |
| --- | --- |
| **Assign to** | Set the deal owner across the selection |
| **Assign to office** | (Organisations) move deals into an office's lens |
| **Set property** | Apply one property value — e.g. tag 30 deals `Cohort = Q3` |
| **Add to directory** | Add the selected companies to one of your public directories |
| **Re-score thesis** | Re-run thesis scoring across the selection |
| **Delete** | Remove from this pipeline (companies themselves are untouched) |

<Note>
  **Set property** and **Add to directory** are enabled per team by Caplia — ask your account manager if you don't see them. Once enabled, every team member can use them.
</Note>
