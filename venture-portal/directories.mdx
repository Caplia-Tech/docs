**Directories** (a.k.a. Host Passports) are public web pages showcasing a curated set of your companies — a cohort page, an award shortlist, a portfolio page — each linking to the company's Passport summary. Perfect for demo days and programme sites.

## Setting one up

<Steps>
  <Step title="Get a directory provisioned">
    Directories are provisioned per team — ask your Caplia contact, or an org admin can create one for an office.
  </Step>
  <Step title="Brand it">
    Title, tagline, logo, and theme colours from the **Host Passports** admin page.
  </Step>
  <Step title="Curate companies">
    Add companies one by one, reorder, feature the highlights — or bulk-add straight from a deal list with **Add to directory**.
  </Step>
  <Step title="Publish">
    Unpublished directories 404 publicly. Flip **Publish** when ready.
  </Step>
</Steps>

## Optional password

For directories that shouldn't be fully public (pre-launch cohorts, judging panels), set an **access password** in the admin page. Visitors see your branding and a password prompt; companies stay hidden until it's entered. It's a light shared gate — one password for everyone — not per-user auth.

## Leads

Directories capture investor interest: visitors can register interest, and leads land in your **Leads** tab with contact details and context.
